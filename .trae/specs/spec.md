# 信途网约车租赁管理系统 - 产品需求文档

## Overview
- **Summary**: 开发一个本地网约车租赁管理程序，用于记录车辆信息、车主信息、司机租赁信息、证件图片管理以及保险信息，并提供到期变色提示功能。
- **Purpose**: 帮助网约车租赁公司高效管理车辆租赁业务，避免租金和保险到期遗漏。
- **Target Users**: 网约车租赁公司管理人员、车主。

## Goals
- 完整记录车辆基本信息（车牌、车型）和车主联系方式
- 管理司机租赁信息（姓名、电话、租赁时间、价格）
- 租金到期前一个月自动变色提示
- 按车辆建立文件夹存储身份证和驾驶证图片，支持点击查看
- 记录保险信息，到期变色提示
- 数据本地持久化存储，无需网络

## Non-Goals
- 不涉及在线支付功能
- 不涉及复杂的财务报表
- 不涉及多用户权限管理
- 不涉及云端同步功能

## Background & Context
- 用户在 Windows 环境下使用
- 需要暗色主题界面，高对比度元素
- 重视界面响应速度和视觉清晰度
- 所有数据存储在本地

## Functional Requirements
- **FR-1**: 车辆信息管理 - 支持添加、编辑、删除车辆记录（车牌号、车型）
- **FR-2**: 车主信息管理 - 每辆车关联车主姓名、联系电话
- **FR-3**: 司机租赁管理 - 记录租赁司机姓名、电话、租赁开始时间、租金价格、下次支付日期
- **FR-4**: 租金到期提示 - 距离下次支付日期 ≤ 30 天的记录变色高亮提示
- **FR-5**: 证件图片管理 - 为每辆车创建文件夹，存储车主/司机身份证和驾驶证图片，支持点击查看大图
- **FR-6**: 保险信息管理 - 记录每辆车的保险公司、保险金额、到期日期
- **FR-7**: 保险到期提示 - 保险到期前 30 天变色高亮提示
- **FR-8**: 数据持久化 - 所有数据保存在本地，关闭程序后数据不丢失
- **FR-9**: 数据搜索和筛选 - 支持按车牌、姓名等关键字搜索

## Non-Functional Requirements
- **NFR-1**: 界面采用暗色主题，高对比度配色
- **NFR-2**: 操作响应时间 < 100ms
- **NFR-3**: 界面简洁直观，无需培训即可使用
- **NFR-4**: 单文件部署，无需复杂安装

## Constraints
- **Technical**: 纯前端实现（HTML + CSS + JavaScript），使用 localStorage 存储数据，使用本地文件系统存储图片
- **Business**: 单机单用户使用模式
- **Dependencies**: 现代浏览器（Chrome/Edge）支持

## Assumptions
- 用户使用 Windows 系统和现代浏览器
- 图片文件通过用户手动选择上传，转换为 Base64 存储在 localStorage
- 数据量在 1000 条以内

## Acceptance Criteria

### AC-1: 车辆信息增删改查
- **Type**: `rule`
- **Given**: 系统已启动
- **When**: 用户点击"添加车辆"按钮并填写车牌、车型、车主姓名、车主电话
- **Then**: 新车辆记录出现在车辆列表中，刷新页面后数据仍存在
- **Pass Condition**: 能够成功添加、编辑、删除车辆记录，数据持久化
- **Evidence**: 手动操作验证，刷新后数据存在

### AC-2: 司机租赁信息管理
- **Type**: `rule`
- **Given**: 已存在至少一条车辆记录
- **When**: 用户选择某辆车，添加租赁司机信息（姓名、电话、开始日期、月租金、下次支付日期）
- **Then**: 该车辆关联显示司机租赁信息
- **Pass Condition**: 租赁信息正确关联并保存
- **Evidence**: 添加后查看详情验证

### AC-3: 租金到期变色提示
- **Type**: `rule`
- **Given**: 存在一条下次支付日期距今 ≤ 30 天的租赁记录
- **When**: 用户查看车辆列表或租赁详情
- **Then**: 该记录以醒目的颜色（如黄色/红色）高亮显示
- **Pass Condition**: 距离到期 ≤ 30 天显示黄色，≤ 7 天或已过期显示红色
- **Evidence**: 修改系统日期或测试数据验证颜色变化

### AC-4: 证件图片存储与查看
- **Type**: `rule`
- **Given**: 已存在车辆或司机记录
- **When**: 用户上传身份证、驾驶证图片，并点击图片缩略图
- **Then**: 图片成功保存，点击后弹出大图预览
- **Pass Condition**: 图片上传后持久化，点击可查看原图
- **Evidence**: 上传图片，刷新后仍可查看

### AC-5: 保险信息管理与到期提示
- **Type**: `rule`
- **Given**: 已存在车辆记录
- **When**: 用户添加保险信息（公司、金额、到期日），到期日距今 ≤ 30 天
- **Then**: 保险信息保存，列表中对应记录高亮变色提示
- **Pass Condition**: 保险信息保存正确，到期前 30 天黄色提示，≤ 7 天或过期红色提示
- **Evidence**: 添加保险信息并设置临近到期日验证

### AC-6: 搜索筛选功能
- **Type**: `rule`
- **Given**: 存在多条车辆记录
- **When**: 用户在搜索框输入车牌号或姓名关键字
- **Then**: 列表实时过滤显示匹配的记录
- **Pass Condition**: 输入关键字后列表正确过滤
- **Evidence**: 输入部分车牌或姓名验证过滤结果

### AC-7: 界面视觉质量
- **Type**: `rubric`
- **Dimension**: 暗色主题视觉效果与可用性
- **Scale**: 1-5
- **Anchors**: 1 = 界面混乱无主题；3 = 基本暗色主题但对比一般；5 = 专业暗色主题，高对比度，到期提示醒目清晰
- **Pass Threshold**: >= 4
- **Evidence**: 界面截图与实际操作体验

### AC-8: 操作响应速度
- **Type**: `rubric`
- **Dimension**: 界面操作流畅度
- **Scale**: 1-5
- **Anchors**: 1 = 明显卡顿延迟；3 = 一般响应偶有延迟；5 = 所有操作瞬时响应无等待感
- **Pass Threshold**: >= 4
- **Evidence**: 连续操作体验评估
