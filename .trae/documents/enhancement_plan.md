## 增强功能实施计划

### 总结
本计划旨在为“信途网约车租赁管理系统”增加数据统计报表、通知提醒功能，并进行图片懒加载、加载状态反馈和安全性优化，以提升用户体验、管理效率和系统健壮性。

### 当前状态分析
- 应用是一个使用 JavaScript 和 Supabase 的单页应用 (SPA)。
- 核心逻辑在 `app.js` 中，数据存储和管理在 `LocalStore` 和 `AppData` 中。
- UI 渲染由 `Render` 模块处理。
- 缺少专门的统计报表页面和通知提醒机制。
- 图片加载目前是同步加载，可能影响性能。
- 用户操作缺乏明确的加载状态反馈。
- 输入字段未明确进行安全消毒处理。

### 拟议变更

#### **1. 加载状态反馈**
*   **目标**：在数据加载和表单提交等异步操作期间，向用户提供明确的视觉反馈。
*   **如何实现**：
    *   **通用加载指示器**：在 `style.css` 中定义一个通用的 CSS Spinner 样式。
    *   **集成到 `app.js`**：
        *   修改 `AppData` 的数据操作方法（如 `fetchVehicles`, `saveVehicle` 等），在操作开始前显示加载指示器，操作完成后隐藏。
        *   在涉及网络请求或长时间处理的 UI 操作（如点击“云同步”按钮、表单提交）时，也显示/隐藏加载指示器。
    *   **影响文件**：[style.css](file:///c:/Users/Administrator/Desktop/新建文件夹/wangyueche/style.css), [app.js](file:///c:/Users/Administrator/Desktop/新建文件夹/wangyueche/app.js)

#### **2. 图片懒加载**
*   **目标**：优化图片加载性能，减少页面初始加载时间。
*   **如何实现**：
    *   **识别图片使用位置**：主要在车辆详情页（证件图片、车辆照片）。
    *   **HTML `loading="lazy"` 属性**：在渲染图片时，为 `<img>` 标签添加 `loading="lazy"` 属性。这是现代浏览器支持的原生懒加载机制。
    *   **JavaScript Fallback (可选，如果需要兼容旧浏览器)**：对于不支持 `loading="lazy"` 的浏览器，可以使用 Intersection Observer API 实现自定义懒加载逻辑。
    *   **影响文件**：[app.js](file:///c:/Users/Administrator/Desktop/新建文件夹/wangyueche/app.js) (渲染图片的部分)

#### **3. 安全性增强 - 输入消毒**
*   **目标**：防止恶意脚本注入 (XSS) 等攻击，确保用户输入数据的安全性和完整性。
*   **如何实现**：
    *   **识别所有用户输入点**：包括车辆信息表单、租赁信息表单、搜索框等所有可输入文本的字段。
    *   **使用DOMPurify库 (推荐)**：
        *   引入 DOMPurify 库（可以通过 CDN 或直接拷贝代码）。
        *   在 `AppData` 中保存数据前，或在渲染用户输入内容到 HTML 之前，使用 DOMPurify 对文本内容进行消毒。
    *   **HTML 实体编码 (备选)**：对于简单的文本显示，可以在渲染前对特殊字符进行 HTML 实体编码。
    *   **影响文件**：[app.js](file:///c:/Users/Administrator/Desktop/新建文件夹/wangyueche/app.js)

#### **4. 通知与提醒系统**
*   **目标**：在车辆保险、年检、管理费等即将到期时，向用户提供及时提醒。
*   **如何实现**：
    *   **数据结构扩展**：在 `AppData` 中管理车辆数据时，确保车辆信息包含保险到期日、年检到期日、管理费到期日等字段。
    *   **提醒逻辑**：
        *   在 `app.js` 的初始化或定时任务中，遍历所有车辆数据。
        *   计算距离各个到期日的剩余天数。
        *   定义提醒阈值（例如：提前 30 天、7 天提醒）。
        *   当满足提醒条件时，在仪表盘或其他显眼位置显示提醒信息（例如，使用 `Toast` 组件或在仪表盘添加提醒列表）。
    *   **影响文件**：[app.js](file:///c:/Users/Administrator/Desktop/新建文件夹/wangyueche/app.js), [style.css](file:///c:/Users/Administrator/Desktop/新建文件夹/wangyueche/style.css) (提醒样式)

#### **5. 数据统计与报表**
*   **目标**：提供车辆运营数据的概览和趋势分析，帮助用户进行决策。
*   **如何实现**：
    *   **新的视图页面**：在 `index.html` 中添加一个新的统计报表视图容器，并在 `app.js` 中集成导航到该视图的逻辑。
    *   **数据聚合逻辑**：
        *   在 `AppData` 或 `app.js` 中实现数据聚合函数，统计车辆总数、不同状态车辆数、租约情况、即将到期的车辆统计等。
    *   **可视化图表**：
        *   引入轻量级图表库（例如 Chart.js 或 ECharts 的轻量版本，通过 CDN 引入）。
        *   在新的统计视图中，渲染图表来展示统计数据（例如：饼图显示车辆状态分布，柱状图显示每月租金收入等）。
    *   **影响文件**：[index.html](file:///c:/Users/Administrator/Desktop/新建文件夹/wangyueche/index.html), [app.js](file:///c:/Users/Administrator/Desktop/新建文件夹/wangyueche/app.js), [style.css](file:///c:/Users/Administrator/Desktop/新建文件夹/wangyueche/style.css) (报表样式)

### 假设与决策
- 所有修改均基于现有的 `app.js` 模块化结构进行扩展。
- 优先使用浏览器原生功能或轻量级解决方案，避免引入过多外部依赖。
- Supabase 的数据结构已包含或易于扩展以支持提醒功能所需的时间字段。

### 验证步骤
- **加载状态反馈**：在执行数据操作和表单提交时，观察加载指示器是否正确显示和隐藏。
- **图片懒加载**：打开车辆详情页，观察图片是否在滚动到视图时才加载（可以在浏览器开发者工具的网络面板中验证）。
- **安全性增强**：尝试在输入框中输入包含 HTML 标签或脚本的代码，保存后查看是否被正确消毒或编码。
- **通知与提醒**：手动修改车辆到期日期，使其触发提醒阈值，检查提醒信息是否正确显示。
- **数据统计与报表**：导航到统计页面，检查图表是否正确渲染，数据是否准确。
