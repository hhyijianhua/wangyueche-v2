安装成手机/桌面APP - 图文步骤
30秒搞定，以后点图标直接打开，不用输网址
0
先把网址复制到完整浏览器打开
如果你现在是在编辑器、内嵌预览窗格里看的，要先把地址 http://localhost:8080 复制到电脑桌面上的 Microsoft Edge 或 Google Chrome 里打开。（编辑器里的预览浏览器不支持安装）
1
点页面右上角的「📱 安装APP」大按钮
就在搜索框右边那个蓝紫色发光的按钮，一按就弹安装框
2
在弹出的小窗口点「安装」
如果按钮没弹框，也可以用浏览器菜单：Edge 右上角 ⋮ → 应用 → 将此站点作为应用安装；Chrome 右上角 ⋮ → 安装「信途网约车租赁管理系统」
3
安装完成
开始菜单和桌面会出现「信途网约车」图标，以后双击就能用，和普通软件一模一样
1
用 Chrome 浏览器打开本页面
不要用微信打开，微信不支持安装
2
点右上角的「安装APP」按钮
或者 Chrome 右上角 ⋮ 三个点 →「安装应用」
3
点「安装」
桌面就出现图标啦，以后点图标直接全屏打开
1
必须用 Safari 浏览器打开
iPhone只支持 Safari 装APP，Chrome/微信都不行哦
2
点底部中间的 ⬆️ 分享按钮
在Safari最下面一排正中间，一个方框往上指的箭头
3
往下滑，找到「添加到主屏幕」
看到蓝色「+」号那个选项，点它
4
点右上角「添加」
回到桌面，最后一页就能看到「网约车管理」图标了
💡 装好后数据和浏览器是共用的，之前录的车辆、司机都在，不用担心丢失
🔐
管理员登录
输入账号密码登录，才能添加 / 编辑 / 删除数据
💡 登录后可在「我的资料」修改自己的密码；只有超级管理员才能新增或删除其他管理员账号。
💡 这里只能改「当前登录的这个账号」的密码，不能改别人的密码（普通管理员）。超级管理员要改别人密码，请到「👥 管理员列表」。
💡 本页仅「超级管理员」可见。可新增 / 删除普通管理员账号，或重置任何普通管理员的密码。如果忘记超级管理员密码，可在浏览器控制台清理 localStorage 中管理员相关项后刷新，系统将恢复出厂超级管理员账号（密码请以你实际设定的为准，或咨询系统搭建人员）。

1

打开 API 设置页面， 在 "Project API keys" 下面，找到 anon public 那行，点右边的 Copy。
⚠️ 不要复制 service_role！那是后台用的，前端只需要 anon public
2
粘贴到下面输入框
3
点「测试连接并保存」
